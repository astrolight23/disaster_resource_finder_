# Disaster Resource Finder

A mobile-first, offline-accessible application that helps individuals locate nearby emergency resources like shelters, food supplies, and medical aid during disasters.

## Features
- Offline access to vital resource information
- Interactive map to find nearby relief centers
- Real-time updates when internet is available
- Lightweight and optimized for low-end devices

## Tech Stack
- Python (backend logic)
- Flask (lightweight backend)
- React Native (mobile frontend)
- SQLite (for local offline database)
